## Featured work

### [BlogSpace — Full Stack](https://github.com/fahim1252375-maker/blogspace-fullstack)
A full-stack blogging application using Node.js, Express, TypeScript, and MongoDB. Includes JWT authentication, password hashing, protected author workflows, CRUD features, and security-focused improvements.

- Backend: [Render service](https://blogspace-fullstack.onrender.com)
- Frontend demo: [Render static site](https://blogspace-frontend-demo.onrender.com)
- Data: MongoDB Atlas `blogspace` database (collections: `blogs`, `users`)

### [ShasthoNote AI](https://github.com/fahim1252375-maker/shasthonote-ai)
A Bangla-English workspace for organising health information before a conversation with a healthcare professional. Includes consultation notes, document workflows, personal tracking, and optional AI-assisted summaries. This is a prototype, not a diagnostic or treatment system.

- [Live backend / application service](https://shasthonote-ai.onrender.com)
- Data integrations documented in the repository include Firebase Authentication and Cloud Firestore.

### [FloodGuard AI](https://github.com/fahim1252375-maker/floodguard-ai)
A bilingual flood and community-preparedness prototype focused on north-eastern Bangladesh. It combines weather context, modelled indicators, family preparedness workflows, and community reporting. Simulated and derived information is identified in the project documentation; this is not an official warning or emergency-response service.

- [Live application](https://flourishing-torrone-237daf.netlify.app)
- [Render service](https://floodguard-ai-39jz.onrender.com)
