## Selected Projects

### [FloodGuard AI](https://github.com/fahim1252375-maker/floodguard-ai)
A bilingual flood and community-health preparedness prototype focused on north-eastern Bangladesh. It combines weather context, modelled indicators, family preparedness workflows, and community reporting. Simulated and derived information is identified in the project documentation; this is not an official warning or emergency-response service.

### [ShasthoNote AI](https://github.com/fahim1252375-maker/shasthonote-ai)
A Bangla-English workspace for organising health information before a conversation with a healthcare professional. It includes consultation notes, document workflows, personal tracking, and optional AI-assisted summaries. It is a prototype, not a diagnostic or treatment system.

### [BlogSpace — Full Stack](https://github.com/fahim1252375-maker/blogspace-fullstack)
A blogging application built with Node.js, Express, TypeScript, and MongoDB. It includes JWT authentication, password hashing, protected author workflows, and security-focused improvements.
