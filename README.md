## What I'm building

### [SortSight AI](https://github.com/fahim1252375-maker/sortsight-ai) · Full-Stack SaaS Prototype

A material-recovery operations platform concept that brings together vision-assisted material classification, contamination review, human-in-the-loop quality checks, sorting workflows, and a digital-twin simulator.

**Stack:** React · TypeScript · Node.js · Express · SQLite · Gemini · Vite · Tailwind CSS

### [BlogSpace](https://github.com/fahim1252375-maker/blogspace-fullstack) · Full-Stack MVP

A full-stack publishing application with author accounts, JWT authentication, password hashing, protected CRUD workflows, server-side ownership checks, and per-IP authentication rate limits.

**Engineering focus:** API design · Authentication · Authorization · MongoDB · Mongoose · 13 automated tests

- [Source code](https://github.com/fahim1252375-maker/blogspace-fullstack)
- [Security improvements — PR #2](https://github.com/fahim1252375-maker/blogspace-fullstack/pull/2)

### [ShasthoNote AI](https://github.com/fahim1252375-maker/shasthonote-ai) · Applied AI Prototype

A Bangla-English workspace for organising health notes, documents, appointments, and personal measurements before conversations with healthcare professionals. Optional AI summaries help users prepare and organise information.

**Stack:** React · TypeScript · Node.js · Express · Firebase Authentication · Cloud Firestore · Gemini

### [FloodGuard AI](https://github.com/fahim1252375-maker/floodguard-ai) · Civic-Tech Prototype

A bilingual flood-preparedness project focused on north-eastern Bangladesh. It explores weather context, water-level scenarios, community reporting, household preparedness, and map-based information.

**Stack:** React · TypeScript · Node.js · Express · Leaflet · SQLite · Gemini

- [Project demo](https://flourishing-torrone-237daf.netlify.app)

### More frontend work

- [BlogSpace Frontend](https://github.com/fahim1252375-maker/blog-application-frontend) — a responsive editorial interface with search, category filters, and a browser-based author workflow.
- [Cinnamon Restaurant](https://github.com/fahim1252375-maker/restaurant-website-frontend) — a responsive restaurant website concept with menu filtering, a gallery, form validation, and WhatsApp request handoff.
