- TypeScript checks, automated unit tests, and Vite production build

## Engineering Highlights

Recent work on BlogSpace has helped me practise more than interface development:

- **Authentication security:** added per-IP registration and login rate limits to reduce repeated authentication attempts.
- **Safer operational responses:** reduced database configuration details exposed by the public health endpoint.
- **Proxy-aware request handling:** added configurable trusted-proxy handling for client-IP detection.
- **HTTP security basics:** introduced baseline Referrer-Policy and Permissions-Policy headers.
- **Testing and quality checks:** worked with TypeScript validation, Node's test runner, production builds, and GitHub pull-request checks.
- **Git collaboration workflow:** used a dedicated security branch and pull request, then merged the reviewed changes into `main`.

[View the merged security pull request](https://github.com/fahim1252375-maker/blogspace-fullstack/pull/2)
